# UD01_Actividad04_Conversores
Conversor de Unidades en Kotlin

Una herramienta de línea de comandos (CLI) desarrollada en Kotlin para realizar conversiones de unidades de distancia, temperatura y divisas de forma rápida e intuitiva.

# 🚀 Características

# 📏 Distancia: Conversión entre metros, kilómetros, millas, yardas y pies.

# 🌡️ Temperatura: Conversión entre Celsius (°C), Fahrenheit (°F) y Kelvin (K).

# 💱 Divisas: Conversión entre diversas monedas

# 💻 Interfaz Interactiva: Menú en consola fácil de usar con validación de entradas.

# ⚡ Rápido y Ligero: Ejecución eficiente sobre la JVM.

# 📋 Requisitos Previos

JDK 17 o superior instalado.

Gradle (mediante el wrapper ./gradlew incluido en el proyecto).

# 🚀 Instalación
